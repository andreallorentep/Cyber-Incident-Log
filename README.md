## 👤 About This Project

This repository is a **cybersecurity incident intelligence log** designed to document and analyze real-world security incidents from a defensive perspective.

The main focus of this project is to build practical knowledge in:
- Threat Intelligence analysis
- Incident classification and understanding
- Attack pattern recognition
- Defensive cybersecurity strategies

This is a **living repository**, meaning it will continuously grow as new incidents are researched and added over time.

## 🎯 Objectives

- Develop strong foundations in SOC analyst thinking
- Understand how real-world cyberattacks are executed
- Identify common attack vectors and defensive gaps
- Practice structured security incident analysis
- Build a professional cybersecurity portfolio for career development

## 🧠 Methodology

Each incident added to this repository is analyzed using a structured approach:

- What happened (incident overview)
- What was affected (assets and data impact)
- How the attack was executed (attack vectors and techniques)
- What vulnerabilities or weaknesses were exploited
- How the attack could have been prevented
- What defensive strategies can be applied

## 🛡️ Security Focus Areas

This project focuses on the following cybersecurity domains:

- Threat Intelligence

- Security Architecture Awareness
- Defensive Security Controls
- Attack Surface Understanding
